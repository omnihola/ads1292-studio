# ADS1292 Studio V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a self-contained ADS1292RECG-FE macOS desktop app for live acquisition, offline review, ECG channel auto-detection, quality metrics, and saved-session export.

**Architecture:** Use a small Python package with separated protocol, data model, CSV IO, signal analysis, and Tk/Matplotlib GUI modules. Live hardware code remains isolated so offline CSV analysis and tests work without a board attached. The GUI is a research-grade acquisition workstation, not medical diagnostic software.

**Tech Stack:** Python 3, pyserial, numpy, scipy, matplotlib, tkinter, pytest.
