**Files:** `io/src/AcquisitionEngine.cpp` (B1); `core/src/acq/AdsProtocolDevice.cpp` + `core/include/ads1292/acq/AdsFraming.h` + `core/src/acq/AdsFraming.cpp` (B2, B3); `qt_runtime/src/QSerialByteTransport.cpp` (B4); `devcli/src/DevCli.cpp` (B9); `qt_runtime/src/AdsPorts.cpp` (C8). **Oracle facts (verified):**
- `device.py iter_stream_samples`: on empty batch does `continue` (only `should_continue()` stops). → **B1**: `AcquisitionEngine.cpp:22` change `if (batch.empty()) break;` to `if (batch.empty()) continue;` and update the header comment. (Keep the `if (!should_continue()) break;` at the top as the sole stop.)
- `device.py acquire_raw_samples`: `start_timestamp = time.time()` captured BEFORE the command; passed to `parse_acquire_payload`. ACK read via `_read_frame_until_end_by` (read byte until START, then type, then bytes until END — VARIABLE length; the ACK payload is just the 2 count bytes), NOT a fixed 51-byte frame. Then data frames via the fixed reader.
  - **B2**: in `AdsProtocolDevice::acquire_raw`, capture wall-clock seconds before `t_.write(...)`: `double start_ts = std::chrono::duration<double>(std::chrono::system_clock::now().time_since_epoch()).count();` and pass `start_ts` (not `0.0`) to `parse_acquire_payload`.
  - **B3**: add to AdsFraming: `Frame read_frame_until_end(IByteTransport& transport);` — scan to `kStart`, read `type`, then append bytes until `kEnd` (variable-length payload; set `ok=true` when END seen; `ok=false` on end-of-input). Use it for the ACK read in `acquire_raw` (replace `read_frame(t_)` for the ACK ONLY; keep `read_frame` for the data-frame loop). The ack payload is then exactly the count bytes.
- `device.py write_cmd`: `ser.write(packet); ser.flush()` (pyserial raises on failure). → **B4**: `QSerialByteTransport::write` — check `port_.write(...) == (qint64)bytes.size()` and `port_.waitForBytesWritten(timeout_ms_)`; throw `std::runtime_error("serial write failed")` on either failing.
- `cli.py cmd_stream`: `try: ... finally: device.stop_stream()`. → **B9**: `devcli::run_stream` — wrap the read loop in try/catch; on exception call `dev.stop_stream()` then rethrow (or use an RAII guard). The normal-path `stop_stream()` stays.
- `device.py list_ads_ports` / `_is_ads_candidate_port`: also matches a port whose **description contains "ADS1x9x"** (the macOS cu.usbmodem/usbserial path-fallback stays deferred). → **C8**: in `list_ads_ports`, also include a port if `info.description()` contains `"ADS1x9x"` (case-insensitive substring) even without the VID/PID match.
