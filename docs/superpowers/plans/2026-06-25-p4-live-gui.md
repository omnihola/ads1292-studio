# P4: Live GUI (status + event console + waveform) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the black-theme live monitoring GUI — a rolling CH2-ECG / CH1-respiration waveform (raw, no filters), a right-side status panel, and a bottom event-annotation console — driven by the P3 `AcquisitionWorker` queue through a QTimer tick loop, with the heavy logic (rolling trace buffer, event-annotation model) extracted into portable, unit-tested core code and the Qt widgets covered by headless smokes.

**Architecture:** Two portable, Qt-free, unit-tested core models — `RollingTrace` (append samples, rolling time window, peak-preserving decimation) and `EventLog` (add point / start-end range / manual range / remove, over the P1 `EventMarker`). The GUI (`gui/`) adds an `IWaveformPlot` abstraction with a vendored-QCustomPlot backend (GPL isolated behind the interface), a `LiveScope` widget, a `StatusPanel`, an `EventConsole`, and a `MainWindow` that assembles the three zones and runs a QTimer tick draining the worker queue into the scope. **Scope is deliberately reduced per the master spec:** raw waveform + status + event annotation only — NO SNR strip and NO display filters (those are P5).

**Tech Stack:** C++17, CMake, Qt6 (Widgets + PrintSupport for QCustomPlot), QCustomPlot (vendored, GPL — internal use only, behind `IWaveformPlot`), Catch2. Re-uses P1 `EventMarker`, P3 `AcquisitionWorker`/`SampleQueue`, the model structs.

## Global Constraints

- **C++17**; `core/` stays pure portable C++ — `RollingTrace` and `EventLog` include only the standard library + core headers, NO Qt. Only `gui/` uses Qt + QCustomPlot.
- **Layering**: `gui → qt_runtime → io → core`, `gui → core`. The portable models go in `core`; the widgets in `gui`.
- **Branch**: work on `c++`; do NOT touch `main`. `build/` is gitignored.
- **Build/test command**:
  ```bash
  CMAKE_PREFIX_PATH="/opt/homebrew/opt/qt;/opt/homebrew/opt/hdf5" cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
  cmake --build build -j
  ctest --test-dir build --output-on-failure
  ```
- **GUI headless verification**: Qt widget tests/smokes run under `QT_QPA_PLATFORM=offscreen`. The app's `--smoke` flag (from P0) is extended to feed the simulator through the GUI and quit.
- **QCustomPlot is GPL, internal-use-only, isolated behind `IWaveformPlot`.** GUI code (LiveScope etc.) depends ONLY on `IWaveformPlot`, never on QCustomPlot types directly. The only file that includes `qcustomplot.h` is the backend `QCustomPlotWaveform.cpp`.
- **Channel mapping (from the README, verbatim):** CH2 = `CH2 ECG Lead I (LA-RA)` (the ECG trace); CH1 = `CH1 raw impedance` / respiration (the respiration trace).
- **Event model semantics (mirror `events.py` / the README):** a point event has `duration_seconds == 0`; a range event has `duration > 0`; quick point/range use the live sample clock; manual ranges take typed start/end seconds. `EventLog` reuses `ads1292::EventMarker` and its `normalized()`.
- **Reduced P4 acceptance:** with the simulator, the GUI shows a live waveform, can Start→record CSV→Stop, and can add point/range events. SNR + display filters are explicitly out of scope (P5).

**Interfaces:**

    - `void append(double value);` (one sample per channel call)

    - `std::vector<double> x() const;` / `std::vector<double> y() const;` — the visible window's time (seconds, relative, ending at the latest sample) and value arrays, **peak-preserving-decimated** to at most `max_points` (default 2000) points so wide windows stay light.

- [ ] **Step 1: Write the failing test**

```cpp
// tests/cpp/test_rolling_trace.cpp
#include "catch.hpp"
#include "ads1292/view/RollingTrace.h"

using ads1292::view::RollingTrace;

TEST_CASE("RollingTrace keeps only the rolling window", "[trace]") {
  RollingTrace t(500.0, 4.0);              // 4 s window @ 500 Hz = 2000 samples
  for (int i = 0; i < 5000; ++i) t.append(static_cast<double>(i));
  REQUIRE(t.size() == 2000);               // older samples dropped
  auto y = t.y();
  REQUIRE_FALSE(y.empty());
  REQUIRE(y.back() == Approx(4999.0));     // newest sample retained
}

TEST_CASE("RollingTrace decimates wide windows to <= max_points", "[trace]") {
  RollingTrace t(500.0, 60.0);             // 30000 samples
  for (int i = 0; i < 30000; ++i) t.append(static_cast<double>(i % 100));
  auto x = t.x();
  auto y = t.y();
  REQUIRE(x.size() == y.size());
  REQUIRE(x.size() <= 2000);               // decimated
  REQUIRE(x.size() > 0);
}

TEST_CASE("RollingTrace x is relative seconds ending at the latest", "[trace]") {
  RollingTrace t(500.0, 4.0);
  for (int i = 0; i < 2000; ++i) t.append(0.0);
  auto x = t.x();
  REQUIRE(x.front() == Approx(0.0).margin(1e-9));
  REQUIRE(x.back() == Approx((2000 - 1) / 500.0).margin(1e-6));
}
```

- [ ] **Step 2: Run to verify it fails.**

- [ ] **Step 3: Implement `RollingTrace`**

`std::deque<double>` (or ring buffer) holding at most `window_seconds * sample_rate_hz` samples; `append` pushes back + trims front. `y()`: if `size() <= max_points` return all; else peak-preserving decimation — split into `max_points/2` buckets and emit each bucket's min then max (so spikes survive), or a simpler stride that keeps min+max per bucket. `x()`: matching time stamps `index / sample_rate_hz` relative to the window start (front = 0). Keep `max_points = 2000` as a named constant.

TEST_CASE("end_range without a start fails", "[events]") {

TEST_CASE("remove_last and remove_at", "[events]") {

  REQUIRE(log.remove_at(0));
  REQUIRE(log.events().size() == 1);
  REQUIRE(log.events()[0].label == "b");

}
