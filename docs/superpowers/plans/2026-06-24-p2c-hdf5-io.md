# P2c: HDF5 I/O Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the C++ HDF5 reader/writer/verifier (`io`, HDF5 official C API + a thin RAII layer) that reproduces the Python `.h5` container — 6 typed sample datasets, a `bundle_json` string dataset, root attrs, and a per-array SHA-256 integrity group — verified structurally against the committed `recording.h5` golden + its sidecar (datasets / dtypes / attrs / hashes / verify-ok).

**Architecture:** A new `io` HDF5 module (`H5Io.{h,cpp}`, guarded by a `ADS1292_BUILD_HDF5` CMake option so the embedded build can drop it) links the HDF5 C library through small RAII handle wrappers. `core` gains a `sha256_hex` (vendored picosha2, golden-tested). Parity is two-sided: (1) **read** — C++ reads the committed `recording.h5` and its extracted structure (each sample dataset's float64-canonical SHA-256, the root attrs, the verify result) equals the committed `recording_h5_sidecar.json`; (2) **write round-trip** — C++ reads `recording.h5`, re-writes the same samples + bundle_json to a temp `.h5`, and that temp file's extracted structure also equals the committed sidecar (HDF5 byte-identity is NOT required; structural/hash equality is the bar).

**Tech Stack:** C++17, CMake, HDF5 C library (Homebrew `/opt/homebrew/opt/hdf5`, has CMake config), picosha2 (vendored single header), Catch2 + nlohmann/json (vendored). The Python oracle (`h5_io.py`) is the reference; the committed `recording.h5` + sidecar are the golden.

## Global Constraints

- **C++17**; `core/` is pure portable C++ (picosha2 is a single header, pure C++ — acceptable in core). `io/`'s HDF5 module uses the HDF5 C library. No Qt/OS APIs.
- **Layering**: `io → core`, `tests → io, core`. The HDF5 module is **optional**: guard `io/src/H5Io.cpp` and its tests behind `option(ADS1292_BUILD_HDF5 "Build the HDF5 I/O module" ON)` so a stripped/embedded build can disable it.
- **Branch**: work on `c++`; do NOT touch `main`. `build/` is gitignored.
- **Build/test command** (every C++ task — note HDF5 is added to the prefix path):
  ```bash
  CMAKE_PREFIX_PATH="/opt/homebrew/opt/qt;/opt/homebrew/opt/hdf5" cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
  cmake --build build -j
  ctest --test-dir build --output-on-failure
  ```
- **The committed `recording.h5` + `recording_h5_sidecar.json` are the golden.** The sidecar's structure is the parity contract:
  - `datasets`: 7 entries — `samples/{timestamp,ch1,ch2,status_byte,board_heart_rate,board_respiration_rate}` and `bundle_json`. Each has `{shape, dtype, sha256}`. For the 6 numeric sample datasets, `sha256` is the **float64-canonical** hash (`sha256` of `np.asarray(values, float64)` C-order bytes). For `bundle_json`, `sha256` is the literal string `"non-numeric"`.
  - `attrs`: `{created_at:"", csv_name:"live_recording.csv", sample_count:"50", sample_rate_hz:"500.0", schema:"ads1292-h5/1"}` (all captured as strings).
  - `verify_ok`: `true`.
- **Sample dataset dtypes (from `h5_io._sample_arrays`, exact):** `timestamp` float64, `ch1` int32, `ch2` int32, `status_byte` uint16, `board_heart_rate` int16, `board_respiration_rate` int16.
- **Two distinct hashes — do not conflate:**
  - **Integrity group** (`integrity` group attrs `sha256_<name>`, written and checked by `verify_recording_h5`): SHA-256 of the array's **native-dtype** little-endian bytes (`np.asarray(array).tobytes()`). On macOS (LE), a contiguous C++ typed buffer (`int32_t[]`, `uint16_t[]`, `double[]`) hashes identically to numpy's `tobytes()`.
  - **Sidecar dataset hash** (parity check only): SHA-256 of the dataset values cast to **float64** C-order bytes. Different from the integrity hash; used only to compare values across the read/write round-trip.
- **`H5_SCHEMA = "ads1292-h5/1"`**. `bundle_json` is a scalar variable-length UTF-8 string dataset. The integrity group holds one `sha256_<name>` attr per sample array (6 total), NOT for `bundle_json`.

```cpp
// io/src/H5Raii.h
#pragma once
#include <hdf5.h>
#include <stdexcept>
#include <string>

namespace ads1292 {
namespace io {
namespace detail {

// Owns an hid_t and closes it with the provided closer (H5Fclose, H5Dclose, ...).
class Hid {
 public:
  Hid() = default;
  Hid(hid_t id, herr_t (*closer)(hid_t)) : id_(id), closer_(closer) {
    if (id_ < 0) throw std::runtime_error("HDF5 returned an invalid handle");
  }
  ~Hid() { reset(); }
  Hid(const Hid&) = delete;
  Hid& operator=(const Hid&) = delete;
  Hid(Hid&& o) noexcept : id_(o.id_), closer_(o.closer_) { o.id_ = -1; o.closer_ = nullptr; }
  Hid& operator=(Hid&& o) noexcept {
    if (this != &o) { reset(); id_ = o.id_; closer_ = o.closer_; o.id_ = -1; o.closer_ = nullptr; }
    return *this;
  }
  hid_t get() const { return id_; }
  void reset() { if (id_ >= 0 && closer_) closer_(id_); id_ = -1; closer_ = nullptr; }

 private:
  hid_t id_ = -1;
  herr_t (*closer_)(hid_t) = nullptr;
};

}  // namespace detail
}  // namespace io
}  // namespace ads1292
```

```cpp
#include "ads1292/io/H5Io.h"
#include <hdf5.h>
#include <vector>
#include "H5Raii.h"

namespace ads1292 {
namespace io {
using detail::Hid;

bool h5_smoke_roundtrip(const std::string& path) {
  const std::vector<int32_t> data = {1, 2, 3, -4};
  {
    Hid file(H5Fcreate(path.c_str(), H5F_ACC_TRUNC, H5P_DEFAULT, H5P_DEFAULT), H5Fclose);
    hsize_t dims[1] = {data.size()};
    Hid space(H5Screate_simple(1, dims, nullptr), H5Sclose);
    Hid dset(H5Dcreate2(file.get(), "v", H5T_STD_I32LE, space.get(),
                        H5P_DEFAULT, H5P_DEFAULT, H5P_DEFAULT), H5Dclose);
    H5Dwrite(dset.get(), H5T_NATIVE_INT32, H5S_ALL, H5S_ALL, H5P_DEFAULT, data.data());
  }
  std::vector<int32_t> read(data.size(), 0);
  {
    Hid file(H5Fopen(path.c_str(), H5F_ACC_RDONLY, H5P_DEFAULT), H5Fclose);
    Hid dset(H5Dopen2(file.get(), "v", H5P_DEFAULT), H5Dclose);
    H5Dread(dset.get(), H5T_NATIVE_INT32, H5S_ALL, H5S_ALL, H5P_DEFAULT, read.data());
  }
  return read == data;
}

}  // namespace io
}  // namespace ads1292
```
